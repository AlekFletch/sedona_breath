# План тестирования

## 1. Автоматические тесты

### Unit-тесты ядра: `entry/src/test` (hypium, 36 тестов)

Запуск: DevEco → *Run 'Local Test'*, `hvigorw … test` или `node tools/node-test/run.mjs`.

| Набор | Что проверяет |
|---|---|
| `BreathPattern` | Длительности циклов всех паттернов; не больше 6 дыханий в минуту для паттернов снижения стресса; ограничения и нормализация свободного ритма; запасной вариант для неизвестного id |
| `BreathEngine` | Границы фаз; точная последовательность и время фаз 4-7-8; пауза и продолжение с середины фазы; время на паузе не засчитывается; отмена снимает все таймеры; восстановление из снимка; отсутствие дрейфа при опаздывающих таймерах; подсчёт циклов |
| `VibrationPlanner` | Вдох 4 с: 9 импульсов, последняя секунда тихая; масштабирование для 3 и 8 с; задержка 7 с: одиночные импульсы в 0–5 с и двойной в 6 с; одинаковая схема для задержки после вдоха и после выдоха; тишина на выдохе; длинный импульс в конце |
| `VibrationScheduler` | Импульсы приходят вовремя; при продолжении прошедшие пропускаются; `stopAll` срабатывает сразу; при выключенной вибрации тишина; новая фаза заменяет сигналы старой |
| `SessionPlanner` | Состав шагов для режимов и длительностей; короткая сессия → паузы по 1 циклу; монотонность по длительности; 10 мин ≈ 600 с; завершение 2–3 цикла / 30–60 с |
| `SupportRules` | Поддерживающее сообщение только при оценке 1–2; рекомендация специалиста при оценке 1 или «Страхе» |
| `SessionController` | Полный сценарий до итога; «Не сейчас» → завершающее дыхание; заметка при «Страхе»; оценка 1; пауза останавливает время и вибрацию; снимок → восстановление в той же фазе; запись «Прервана» с этапом |

### Инструментальные: `entry/src/ohosTest` (на часах или эмуляторе)

| Набор | Что проверяет |
|---|---|
| `SettingsStore` | Настройки сохраняются и читаются обратно; снимок сохраняется, загружается и очищается |
| `HistoryRepository` | Вставка и сортировка, счётчик «сегодня», последняя завершённая, лимит 10, удаление всего |

### Статическая проверка: `node tools/check-i18n.mjs`

Паритет ключей ru/en/es, плейсхолдеры, лимиты длины для экрана часов, отсутствие захардкоженного текста в `.ets`, неиспользуемые и неизвестные ключи.

## 2. Ручные сценарии на часах

Перед прогоном: свежая установка, вибрация включена, звук и «Не беспокоить» в обычном состоянии. Тот же набор нужно прогнать на устройстве `wearable`; для Watch Fit 4 он применим после переноса в lite-JS (см. LIMITATIONS §1).

### A. Первый запуск
1. Запустить приложение → открывается онбординг с дисклеймером. Свайп «назад» → приложение закрывается. Повторный запуск снова открывает онбординг.
2. «Принимаю» → главный экран: «Пока нет практик», «Сегодня: 0».

### B. Полный цикл, «Полная практика», 3 мин, 4-7-8
1. Setup: длительность 3, режим «Полная практика», «Дыхание 4-7-8», вибрация вкл → «Начать».
2. Вступление: три подсказки по 3 с; касание пропускает их.
3. Дыхание: круг растёт на вдохе 4 с (частая дробь, на 4-й секунде тишина), стоит на задержке 7 с (импульсы каждую секунду, двойной в 7-й), сжимается на выдохе 8 с (тишина). Время «Осталось» уменьшается.
4. Вопрос 1 из 5 → «Замечаю» → выбор эмоции («Напряжение») → дыхание (1 цикл).
5. Вопросы 2–4: кнопки «Да / Нет / Не знаю / Пропустить»; после каждого 1 цикл дыхания; текст не обрезается.
6. Вопрос 5 «Когда?» → «Сейчас».
7. Завершающее дыхание: «Спасибо. Вернёмся к дыханию», 3 цикла, в конце один длинный импульс, затем тишина.
8. Оценка: «Как ты себя чувствуешь сейчас?» → 4 → мягкое сообщение → «Далее».
9. Итог: длительность, циклы (2 + 4 + 3 = 9), режим, «Эмоция до: Напряжение», «Оценка после: 4 из 5» → «Сохранить» → тост «Практика сохранена» → главный экран: «Сегодня: 1», «Последняя».
10. История: запись «Завершена», «До: Напряжение», «После: 4 из 5».

### C. Быстрый режим и ветки
1. «Быстрое снятие стресса», 2 мин, 4-6: 4 вопроса, экрана эмоций нет, после вопросов по 1 циклу.
2. «Полная практика»: вопрос 5 → «Не сейчас» → «Хорошо. Вернёмся к дыханию» → завершающее дыхание.
3. Эмоция «Страх» → заметка с рекомендацией поговорить с близким человеком или специалистом → «Далее».
4. Оценка 1 → поддерживающее сообщение и рекомендация специалиста. Оценка 2 → только поддерживающее сообщение. «Пропустить» → мягкое сообщение, в итоге нет строки «Оценка».
5. Все пять паттернов: длительности фаз совпадают с таблицей; у свободного ритма в настройках вдох 3–8 с, выдох 4–12 с, сумма ≥ 10 с.

### D. Пауза и завершение
1. «Пауза» → вибрация прекращается сразу (в том числе посреди дроби вдоха) → «Продолжить» → круг и вибрация продолжаются с той же точки фазы.
2. Свайп «назад» во время дыхания → «Продолжить / Завершить сейчас / Завершить и сохранить».
3. «Завершить сейчас» → главный экран, в истории ничего не появилось.
4. «Завершить и сохранить» на вопросе 3 → в истории «Прервана», «Остановка: вопросы».

### E. Прерывания
1. Закрыть экран ладонью во время вдоха → вибрация прекращается сразу. Открыть экран → «Практика на паузе. Прогресс сохранён» → «Продолжить» → продолжение с той же фазы.
2. Нажать кнопку, чтобы уйти на циферблат, → вернуться в приложение → то же поведение.
3. Входящий звонок во время задержки → после звонка «Продолжить» или «Завершить».
4. Принудительно закрыть приложение в списке недавних (или `hdc shell aa force-stop com.alekfletch.sedonabreath`) → запустить снова → «Практика не завершена» → «Продолжить» → сессия на паузе в той же точке.
5. Низкий заряд (≤ 10 % без зарядки): начать практику → в течение 30 с «Низкий заряд. Прогресс сохранён» → «Продолжить» или «Завершить». С подключённой зарядкой предупреждения нет.
6. Экран не гаснет сам во время дыхания; на паузе гаснет по обычному таймауту.

### F. Настройки и данные
1. Язык: English → интерфейс сразу на английском; Español → на испанском; «Системный» → тост о перезапуске, после холодного старта язык системы (неподдерживаемый язык → русский).
2. При системном размере шрифта «Крупный» вопросы и кнопки не обрезаются (экраны прокручиваются).
3. Значения по умолчанию (паттерн, длительность, режим, вибрация) появляются на экране Setup.
4. «Удалить всю историю» → подтверждение → «Отмена» ничего не меняет; «Удалить» → история пуста, «Сегодня: 0».
5. Вибрация выкл → ни одного импульса за всю сессию, включая длинный в конце.

### G. Разрешения и Health Kit
1. Huawei Health → Вкл → экран-пояснение → «Отмена» → переключатель остаётся «Выкл», никаких системных диалогов.
2. «Разрешить» без client_id или на часах без Health → тост «Health недоступен», приложение работает.
3. Пульс → пояснение → «Разрешить» → в системном диалоге «Запретить» → тост «Доступ не выдан…», переключатель «Выкл». Практика проходит полностью.
4. С выданным доступом: итог показывает «Пульс: N уд/мин», если за время практики в Health есть замеры; если замеров нет, строки нет.
5. Отключить Huawei Health → авторизация снята; в следующей практике пульса нет.

### H. Карточка быстрого старта
1. Добавить карточку «Быстрая практика» (если модель поддерживает) → нажать «3 мин» → сразу стартует быстрый режим на 3 минуты.
2. Нажать карточку во время идущей практики → текущая практика не заменяется.
3. Без принятых условий → сначала онбординг, после «Принимаю» главный экран (практика сама не стартует).
